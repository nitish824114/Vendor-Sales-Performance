# Vendor-Sales-Performance
The Vendor sales performance is a Power BI, python and SQl project designed to analyze vendor and brand performance in the retail and wholesale industry. It provides actionable insights into sales, purchases, profitability, and inventory efficiency to help businesses optimize pricing, vendor relationships, and stock management.

**Business Objective**
The project aims to:

- Identify underperforming brands that need promotional or pricing adjustments.

- Determine top vendors contributing most to sales and gross profit.

- Analyze the impact of bulk purchasing on unit costs and profitability.

- Assess inventory turnover to reduce holding costs and improve efficiency.

- Compare profitability variance between high-performing and low-performing vendors.

**Tools & Technologies**
Power BI for data visualization and dashboard design.

Python / Excel for data preprocessing and statistical analysis.

SQL for data retrievalfrom database.

**Highlights**
- Top 10 vendors contribute 65.69% of total purchases — indicating vendor dependency risk.

- Bulk purchasing reduces unit cost by 72%, improving profitability.

- Low-performing vendors show higher margins but lower sales volumes — suggesting pricing inefficiencies.

- Statistical validation confirms significant differences in profit models between top and low-performing vendors.

**Outcomes**
This dashboard empowers decision-makers to:

- Optimize pricing and promotional strategies.

- Diversify vendor partnerships to mitigate supply chain risks.

- Improve inventory management and reduce unsold capital.

- Enhance profitability through data-driven insights.
